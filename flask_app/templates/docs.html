📌 Project Overview

The Electric Vehicle Market Performance & Insights project is a comprehensive data analytics solution built on the SkillWallet platform under the "Data Analytics with Tableau" program. It analyzes global EV market trends, manufacturer performance, battery technology adoption, and customer satisfaction.

Step 1: Data Collection & Extraction

The dataset was constructed from publicly available EV market data covering 50 vehicle models from 22 global brands for model year 2022–2023.

Attributes collected: Vehicle ID, Brand, Model, Category, Year, Battery Technology, Battery Capacity (kWh), Driving Range (km), Charging Speed (kW), Price (USD), Annual Sales, Market Share (%), Manufacturing Country, Customer Rating, Lifespan (years), CO₂ Saved/year (kg).

Tableau Connection: Connect Tableau Desktop to the SQLite database at data/ev_market.db using the SQLite driver, or directly import data/processed/ev_cleaned.csv.

Step 2: Data Preparation

Run the data preparation script to clean and engineer features:

cd notebooks
python data_preparation.py

This script performs:

  • Duplicate removal and missing value imputation
  • Price Segment classification (Budget / Mid / Premium / Luxury)
  • Range Tier categorization
  • Charging Speed category labeling
  • Revenue estimation (Price × Sales)
  • Value Score calculation (Range per $1000)
  • CO₂ Impact totals
  • Regional grouping (NA / APAC / EU)

Step 3: SQL Operations

Execute the SQL script to set up the MySQL database (optional — SQLite is used by default):

mysql -u root -p < data/sql/create_ev_database.sql

Key SQL queries included: brand aggregations, category analysis, battery tech distribution, manufacturing country breakdown, top-10 models, price segment analysis, CO₂ impact, and a KPI overview query.

Step 4: Data Visualizations (7 Unique Chart Types)

  1. Horizontal Bar Chart — Annual Sales by Brand
  2. Pie / Donut Chart — Battery Technology Market Share
  3. Scatter Plot — Price vs Driving Range (colored by Category)
  4. Treemap — Market Share by Brand & Category
  5. Geographic Map — Sales by Manufacturing Country
  6. Line/Area Chart — Customer Rating Distribution by Category
  7. Bubble Chart — Brand Sales vs Rating vs Price

Step 5: Dashboard Design

The Tableau dashboard combines all 7 visualizations in a responsive layout with:

  • Global filters for Category, Brand, Battery Tech, Country
  • KPI header tiles (Total Sales, Avg Rating, Max Range, Market Leaders)
  • Highlight actions between charts
  • Tooltip customization with brand logos
  • Mobile-responsive layout using Device Designer

Step 6: Story (5 Scenes)

  1. Market Overview — Global EV landscape summary
  2. Brand Leaders — Competitive analysis & market share
  3. Battery Technology — Tech adoption & performance comparison
  4. Range & Price Equation — Value analysis across segments
  5. Sustainability Impact — CO₂ savings & green mobility

Step 8: Web Integration

Publishing to Tableau Public:

  1. Open Tableau workbook
  2. Server → Tableau Public → Save to Tableau Public
  3. Copy the embed code for Dashboard and Story
  4. Paste into dashboard.html and story.html

Running Flask:

pip install -r requirements.txt
python notebooks/data_preparation.py
cd flask_app
python app.py

Access at: http://localhost:5000
